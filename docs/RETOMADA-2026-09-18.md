## Preparar o computador

Com Git, Node.js e VS Code instalados, em uma pasta onde você possa trabalhar:

```powershell
git clone --branch release/uat-2026-09-18 https://github.com/jowbryan-vp/finflow.git FinFlow

cd tests/financial-engine
npm ci --ignore-scripts

```

## Abrir o aplicativo

Use um servidor local (por exemplo, Live Server do VS Code). O app atual exige autenticação Google e o Client ID configurado pelo usuário. A URL local precisa corresponder à configuração OAuth já utilizada. Uma clonagem não transfere Client ID, sessão do navegador ou dados locais. Não é suficiente abrir o HTML por file:// para garantir o login.

Se a tela pedir Client ID ou houver erro de redirecionamento, envie o texto do erro ao coordenador; não cole tokens no chat ou no repositório. Drive autenticado no novo computador ainda não foi validado. Antes de testar alterações com seus dados, mantenha um backup privado; nunca coloque esse backup no Git.

## Validação como usuário

1. Conferir disponível real separadamente de comprometido, projetado e potenciais.
2. Escolher salário principal e confirmar que o recebimento de outro salário não muda o ciclo.
3. Confirmar que receitas potenciais não aumentam o disponível ou a projeção.
4. Conferir que compras no cartão saem pela fatura uma única vez.
5. Com histórico apenas de fixas/parcelas em um dos três meses anteriores, conferir aviso de histórico insuficiente para variáveis.
6. Anotar tela, operação, resultado esperado e observado para qualquer divergência, sem expor dados pessoais em issues públicas.
